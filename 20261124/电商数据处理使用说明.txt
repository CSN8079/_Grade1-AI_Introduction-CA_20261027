电商订单数据清洗与可视化：学生材料包

一、文件用途
sales_data.csv：30 行模拟教学数据，不是真实订单。每行是一条订单记录，价格单位为元，数量单位为件。
data_warmup.py：可直接运行的热身示例。先读取正式数据确认文件可用，再用另一组校园义卖数据演示检查、替换、填充、去重、分组和画图。
实验记录模板.txt：复制后填写。

二、运行准备
解压后，把代码和 CSV 保持在同一文件夹。沿用此前已配置的 Python 环境。
如提示缺少 pandas 或 matplotlib，在终端安装到运行本程序的同一个 Python 环境：
python -m pip install pandas matplotlib
如果此前使用 python3 或 py，以上命令中的 python 也相应替换。
在本文件夹中运行：python data_warmup.py
也可以在此前的编辑器中运行整个文件。不要将 .py 程序当成 Notebook 运行。
热身会生成 warmup_clean.csv 和 warmup_chart.png，不修改 sales_data.csv。
程序会自动尝试中文字体；没有合适字体时，热身图使用英文标签。

三、正式任务
任务一：新建 clean_sales.py，读取原始 CSV，检查数据；统一“微信”为“微信支付”；选择并解释价格缺失填充方法；删除完全重复行；验证后保存 sales_clean.csv。
先画流程，再写代码。检查缺失数、支付方式写法、重复数与行数变化。
注意：示例的填充方法只是演示，不代表所有数据都必须用同一方法。是否先去重也会影响均值或中位数，请记录实际处理顺序。不要人为把中位数说成异常值导致均值偏高的必然结论。

任务二：新建 analyze_sales.py，读取 sales_clean.csv，计算总金额＝价格×数量；按商品类别统计销售额、降序输出并画柱状图，保存 category_sales.png。
图应有标题、轴标签和单位。若电脑中文字体不可用，可以在图中使用对应英文标签，但要在记录中解释对应关系。
核对一笔订单的计算，核对类别销售额合计和所有订单总金额合计。不同合理填充方案可能产生不同总额，应评价方法与计算的一致性。

四、AI 协作与独立验收
至少记录一次具体问题、AI 建议、自己的理解和验证证据。没有报错也可通过讨论处理方案完成记录。
独立验收时暂停 AI，可查阅个人笔记。另存 payment_sales.py，改为按支付方式汇总并更新图表标签；核对总金额不变并解释原因。

payment_sales.py 和实验报告。
